# Input Context

하네스가 시작하기 전에 이 목록의 파일이 모두 있어야 한다.
판정: 아래 "필수 파일"을 `test -f`로 하나씩 확인했을 때 모두 통과해야 시작한다. 하나라도 없으면 멈춘다.

## 필수 파일

| 파일 | 역할 |
|---|---|
| prd.md | 서비스 맥락 (SSOT) |
| design.md | 디자인 규칙·토큰 선택 기준 (SSOT) |
| tokens/tokens.css | 코드용 토큰 값 |
| story-service.md | 판정 기준: 유저스토리, 어기면 안 되는 것 |
| story-work.md | 파이프라인 재료: 실제 작업 흐름, 게이트, 경계 |
