# Purpose

## 실행 단위

- 한 번 실행할 때 컴포넌트 1개를 만든다.
- 인자 `component`는 다음 값 중 하나만 허용한다: `image-slider` | `video-player` | `playback-progress`
- `playback-progress`는 선택 실행이다. video-player에 재생바를 쓰기로 했을 때만 실행한다.
- 세 컴포넌트가 함께 따르는 규칙은 매번 같은 SSOT 파일 `rules.yaml`을 읽는다. 근거: PRD 10장

## 사용자

- 실행, 승인, 결과 사용을 모두 1명이 한다 (기획자 겸 디자이너 겸 개발자).
- 개발 전달 문서는 같은 사람이 개발 단계에 들어갈 때 읽는 입력 파일이다.

## 범위

- story-work.md의 1~7단계를 포함한다.
- 하네스는 개발 전달 문서를 만드는 데까지만 한다. 실제 코드 구현은 하지 않는다 (경계 B2에서 멈춤).

## 완료 기준

대상 컴포넌트의 필수 상태가 Figma에 모두 있고, 모든 게이트가 PASS이며, 개발 전달 문서 파일이 있다.

- 필수 상태 목록은 `rules.yaml`의 `required_states`를 따른다.
- video-player에서 재생/일시정지 버튼 외의 컨트롤(재생바, 시간 정보, 음소거, 자막, 전체화면 등)은 선택이다.

근거: PRD 14장

## PRD와 다르게 정한 것

- 재생바와 시간 정보를 선택으로 둔다. PRD는 둘 다 필수로 둔다(6-2의 4~6번, MVP 필수 7·8번). 사용자 결정 (2026-09-29).
